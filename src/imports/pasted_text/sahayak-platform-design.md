Design a premium, clean, structured, and highly accessible web platform UI called “Sahayak – A Unified Support Ecosystem”, optimized for senior citizens, specially-abled individuals, and general users. The platform should feel calm, trustworthy, modern, and extremely easy to use, with a strong focus on clarity, guided navigation, and accessibility. The design must follow a clean SaaS style with a minimal, non-cluttered interface, consistent spacing using an 8px grid system, 12px rounded corners, soft shadows, and a spacious layout that avoids crowding. Typography should be highly readable (Inter or Poppins), and the color palette should use Primary #2563EB, Secondary #10B981, Accent #F59E0B, and Background #F8FAFC. The platform should follow a progressive and user-friendly flow. The landing page should act as an emotional and welcoming entry point and should not expose detailed features. It must include a clean top navbar with Logo, About, How It Works, Explore, Impact, Careers, and Login/Signup. The hero section should have an emotional headline, supportive text, and a clear CTA like “Get Started”, along with a subtle looping background video or AI-generated illustration showing real-life support scenarios such as helping elderly people, assisting specially-abled individuals, and community care. Below the hero section, include well-structured sections like Accessibility Support, Community & Care, and Contribution & Impact, followed by impact statistics and testimonials to build trust. The layout should feel premium, breathable, and visually engaging without clutter. A floating chatbot button should be placed at the bottom-right, opening a clean side panel that guides users, suggests actions, helps navigation, and optionally supports voice interaction. Unlike strict role-based systems, users should be able to sign up and log in normally without selecting a role initially. After login, users should enter a clean “Explore Dashboard” where all major platform features are visible and accessible for exploration. The dashboard should use a structured layout with a top header containing a global search bar, notifications, profile section, and accessibility controls such as font size adjustment and high contrast toggle. An optional collapsible sidebar may be included for better navigation. All features such as OTM Accessibility Map, Travel/Assistant Booking, Government Schemes, Community, Story Sharing, Donation, Caretaker Booking, and Learning or Support modules should be displayed as modern, well-designed cards with icons, short descriptions, soft gradient backgrounds, and smooth hover animations. The layout must remain spacious, avoiding dense grids and maintaining a premium SaaS feel. Each feature should have its own dedicated page with a clear layout and a separate internal search bar for better usability. For example, the OTM Accessibility Map should have a full-width map with a side filter panel, location search bar, and an “Add Tag” button. The story-sharing module should include a searchable grid of stories with upload options for text, voice, or video. Donation and orphanage-related modules should include structured tables, filters, and clean card layouts. Government schemes and community sections should be simple, readable, and easy to navigate. A key feature to include is the Travel/Assistant Booking system, where users can browse multiple assistant profiles displayed in clean cards with details like name, experience, rating, and specialization. Users should be able to filter assistants and initiate booking by clicking “Book Now”. However, before completing any booking or sensitive action (such as hiring a caretaker, making a donation, or volunteering), the system must prompt the user to complete role-based verification or registration (such as selecting role: caretaker, donor, volunteer, etc.). This ensures flexibility in exploration while maintaining structured data and trust during actual transactions. Accessibility must be deeply integrated across the platform. Include font size controls (small, medium, large), high contrast mode, large touch-friendly buttons, clean typography, and calm color usage. Add an advanced voice navigation system with a floating microphone button positioned at the bottom-left that allows users to navigate the platform using voice commands without using a cursor. Additionally, implement a text-to-speech feature where hovering over any important text element triggers an audio reading of that content, helping users who have difficulty reading. The chatbot (bottom-right) and voice assistant (bottom-left) must both be draggable, repositionable, and should never overlap or block important UI elements. The chatbot should always open in a side panel and act as a helpful assistant rather than a distraction. Include a dedicated Careers section where users can explore and apply for roles like caretaker or personal assistant. This section should include clean job cards, filters, and a simple, accessible application form. Maintain consistent card styles, proper spacing, strong visual hierarchy, and balanced layouts throughout the platform. The entire experience should feel emotionally engaging, easy to navigate, inclusive, and human-centered, using subtle animations, soft visuals, and thoughtful interactions without overwhelming the user. The final UI should feel like a supportive digital assistant that guides users step-by-step, rather than a complex system, ensuring accessibility, trust, and ease of use for all types of users.
